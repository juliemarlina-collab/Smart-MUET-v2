MUET 800/4 · WRITING

Plan clearly.Write with purpose.

Use PEEL to turn a basic idea into a focused, developed paragraph that stays connected to the task.

Tap PEEL to learn the technique

One memorable technique. Four simple moves.

P — POINT: State the paragraph’s main idea clearly.
1Identify the task, audience and purpose before writing.
2Plan the main ideas before developing sentences.
3Leave time to check organisation, language and task fulfilment.

Example Idea

Universities should provide more flexible learning spaces.

Tap P/E/E/L to build the paragraph.
✓Use clear topic sentences and logical paragraphing.
✓Develop fewer ideas well instead of listing many weak points.
✓Use linking words only when they show a real relationship between ideas.
Explain: This is important because… / This can lead to…
Example: For example… / A clear example is…
Link: Therefore… / As a result… / This shows that…
✓Answer the exact task, not a memorised topic.
✓Plan before drafting.
✓Support each major point with development.
×Writing long introductions that do not answer the task.
×Using advanced words inaccurately.
×Repeating the same idea without explanation or evidence.
