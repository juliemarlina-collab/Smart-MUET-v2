# Smart MUET V2 Matriculation Pilot Test

## Intended scope

This pilot contains three complete practice stages only:

1. Vault 1 — guided practice
2. Vault 2 — independent practice
3. Mock Practice 1 — exam-style practice

Each stage contains Speaking, Reading, Listening and Writing.

## Learner test sequence

1. Register one test learner and confirm the `Students` sheet receives a row.
2. In Vault 1 Listening and Reading, answer several questions, refresh the page and confirm the selected answers remain.
3. Submit an incomplete objective paper and confirm it displays a result but does not mark the component complete.
4. Complete and submit each Vault 1 component. Confirm the Vault 1 hub displays `4 / 4` and the main Vault displays `1 / 3`.
5. Repeat for Vault 2 and confirm the main Vault displays `2 / 3`.
6. Complete all four Mock Practice 1 components and confirm the main Vault displays `3 / 3`.
7. Open Progress and confirm each completed stage displays four component scores, a total out of 360 and a practice band.
8. Confirm Listening and Reading attempts appear in the backend component sheets.

## Expected objective-paper calculations

- Listening: `round(correct / 30 × 90)`
- Reading: `round(correct / 40 × 90)`
- Stage total: Speaking + Reading + Listening + Writing, maximum 360

## Device checks

- Test Google Drive audio playback on the intended student network.
- Test microphone permission, recording and speech recognition in Chrome.
- Test one mobile, one tablet and one desktop viewport.
- Treat automated Speaking and Writing results as practice estimates, not official MUET grades.
